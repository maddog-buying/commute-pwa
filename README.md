# 上班路線

石碇服務區到國票金控，比較三條路線現在的預估時間。純 HTML/JS，沒有 build。

## 部署資料中繼（Apps Script）

高公局與臺北市的開放資料不允許網頁跨網域讀取，所以要一支 Apps Script 代抓。

1. 到 https://script.google.com 建立新專案，把 `backend/Code.gs` 全部貼上。
2. 部署 → 新增部署作業 → 類型選「網頁應用程式」。執行身分選「我」，存取權選「所有人」。
3. 把拿到的 `/exec` 網址填進 `config.js`，並把 `sw.js` 的 `CACHE` 版本 +1。

改了 `Code.gs` 之後要到「管理部署作業 → 編輯 → 新版本」才會生效。

## 本機預覽

launch config `commute-pwa`（port 8091）。

- `?demo`：虛構的塞車情境，看畫面用。
- `?dev`：在瀏覽器裡跑真正的 `backend/Code.gs`，資料是即時的。

## 分析怎麼算

每段路的時間加總，來源分三種：

| 路段 | 來源 |
|---|---|
| 國五、國三 | 高公局路段旅行時間（每分鐘） |
| 南港聯絡道、國五接國三匝道 | 高公局車輛偵測器（每分鐘） |
| 環東、堤頂大道、研究院路 | 臺北市交控中心路段車速（約 5 分鐘） |
| 文山路、北深路、深南路、南深路、經貿二路 | 沒有公開即時資料，用 `routes.js` 裡的估算車速 |

路線與估算車速都在 `routes.js`。實際開幾次後，可以照實際時間調整 `est`（離峰、尖峰）與 `delay`（號誌秒數）。

臺北市的 `GetVD.xml` 停在 2024 年，要用 `GetVD.xml.gz`。任何來源超過 30 分鐘沒更新就不採用。
